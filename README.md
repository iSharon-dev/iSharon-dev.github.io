# YLX Visual Portfolio

应俐萱个人视觉传达设计作品集网站。

## GitHub Pages 发布

1. 新建公开仓库，名称必须为 `你的GitHub用户名.github.io`。
2. 在仓库的上传页面依次上传“第1批”和“第2批”的内容。
3. 打开 `Settings → Pages`，将 `Source` 设置为 `GitHub Actions`。
4. 等待仓库 `Actions` 页面中的发布任务变为绿色。
5. 访问 `https://你的GitHub用户名.github.io/`。

网站使用 Next.js 静态导出；每次在 `main` 分支更新文件后都会自动重新发布。
